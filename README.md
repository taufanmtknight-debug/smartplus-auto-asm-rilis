# Smartplus AUTO ASM — rilis

Userscript Violentmonkey untuk Smartplus V2.2 (IGD).

## Install
1. Pasang ekstensi **Violentmonkey** (Chrome / Firefox / Edge, juga Firefox/Kiwi di HP).
2. Buka link berikut lalu klik **Install**:
   https://raw.githubusercontent.com/taufanmtknight-debug/smartplus-auto-asm-rilis/main/Smartplus_AUTO_ASM.user.js
3. Selesai. Update berjalan otomatis setiap ada versi baru.
